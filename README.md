# 数字金融使用与大学生过度消费倾向——实证分析代码

本项目基于 198 份大学生问卷数据，研究数字金融使用（DFU）与大学生过度消费倾向（OP）之间的关系。

研究还考察三方面问题：
- 金融素养（主观、客观维度）在其中可能发挥的作用；
- 这一关系在不同群体之间的异质性；
- 结论的稳健性，通过多种稳健性检验加以验证。

全部数据处理、统计分析、模型估计和图表输出均使用 Python 完成，运行一次 `main.py` 即可得到全部结果。

## 变量构造

**过度消费倾向（OP）**
- 第 26 题五个 Likert 题项取均值，标准化后记为 ZOP。
- 五题之和 OPsum（5–25）作为 Ordered Logit 的被解释变量。

**数字金融使用（DFU）**
- 由四个维度等权平均得到，标准化后记为 ZDFU。
- 支付维度：第 12 题手机支付占比，(取值−1)/3 后进入指数。
- 信贷维度：第 13 题是否使用信用支付，原始 0/1 直接进入。
- 强度维度：第 14 题分期或先用后付使用频率，取值/2 后进入。
- 理财维度：第 18 题是否通过互联网购买金融产品，原始 0/1 直接进入。

**金融素养（FL）**
- 主观金融素养 SFL：四项自评得分的均值。
- 客观金融素养 OFL：四道知识题正确率。
- 两者各自标准化后等权平均，再标准化得到 ZFL。

**控制变量**
- 分类变量以虚拟变量形式进入模型：性别、年级、专业、学校城市层级、生源地、独生子女、月均生活费。
- 父母平均受教育程度（parentedu，数值越大学历越低）作为连续变量进入。
- 基准组依次为：男、大四/大五、理工类、新一线、省会及以上、非独生子女、2000—3000 元。

## 主要结果

- **基准回归**：ZDFU 的系数在四个模型中分别为 0.387、0.373、0.363、0.373，均在 1% 水平上显著。数字金融使用每提高 1 个标准差，过度消费倾向约提高 0.37 个标准差。
- **稳健性检验**
  - Ordered Logit 系数为 0.775，在 1% 水平上显著，对应 OR 为 2.171。
  - 分维度回归中，信贷（0.347）、理财（0.212）、强度（0.280）三个维度显著为正，支付维度不显著。
  - 五个分项被解释变量的系数均显著为正。
- **机制分析**：ZDFU 与综合金融素养（0.215***）、主观金融素养（0.277***）显著正相关，与客观金融素养（0.064）关系不显著。
- **异质性检验**
  - 各组系数均为正，在独生子女、父母教育水平较高、生活费高于 2000 元的学生中更大。
  - 交互项检验显示组间差异在统计上均不显著（p 值 0.24–0.77），异质性结果宜理解为样本内部关系强弱的差异。
